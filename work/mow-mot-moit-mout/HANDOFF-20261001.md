```text
NHÓM CHUNG
   → sinh → NHÓM RIÊNG
              → ĐỐI TƯỢNG
                 → BẢN GHI
```

hoặc:

```text

   → CONFIG TRỰC TIẾP
      → ĐỐI TƯỢNG
         → BẢN GHI
```

## 2.4. Đối tượng ≠ Bản ghi
Đây là chỗ từng hiểu sai, phải giữ đúng.

**MOW / MOT / MOIT / MOUT / Field là lớp định nghĩa / template / đối tượng dùng lại.**

Ví dụ:
- `MOT Làm hồ sơ` = định nghĩa một công việc ⇒ **chưa phải bản ghi**.
- `Làm hồ sơ cho Đơn hàng DH-001` = **bản ghi thực tế**.

Tương tự:
- Field `Ngày nộp hồ sơ` = định nghĩa Field.
- Giá trị `30/09/2026` của DH-001 = bản ghi/giá trị thực tế.

MOW là **quy trình**. Có nhiều loại MOW/quy trình:
- quy trình Đề xuất tạo mới;
- quy trình Khai báo;
- v.v.
